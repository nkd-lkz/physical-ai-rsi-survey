# Public embodied RSI literature repository

This repository contains public literature notes only. Read `survey-rsi/AGENTS.md`,
`survey-rsi/SCOPE.md`, and `survey-rsi/MAINTENANCE.md` before changing the survey.
Use public primary sources for claims and figures. Keep abstract-only leads in the
candidate queue, preserve evidence boundaries and historical daily logs, and run
`python survey-rsi/scripts/check_boundary.py` before committing.

Do not import private project hypotheses, experiment plans, implementation notes,
internal screenshots, or links to unrelated project areas.
